## Context & Setup

When serving content pages from an origin server, network latency to international visitors often dominated response time. By pushing response caching to edge nodes, pages are delivered directly from the visitor's nearest point of presence.

```typescript
// Header configuration applied to edge handlers
export const revalidate = 86400 // 24 hours
```

## Key Findings

1. Origin server load decreased by 92% during synthetic traffic tests.
2. First Contentful Paint (FCP) improved in direct correlation with the TTFB decrease.
