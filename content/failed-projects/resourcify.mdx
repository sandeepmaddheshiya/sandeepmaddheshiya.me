## Post-Mortem Details

### The Product & Tech Stack
- **Client App:** Cross-platform mobile client built with **Flutter & Dart** for responsive performance across diverse Android screen sizes.
- **Communications:** **SendGrid** API integration for automated verification, resource updates, and transactional student notifications.
- **Content:** Curated repository of semester study materials, subject notes, and previous year exam question papers.

### Key Metrics
- **Downloads:** 1,000+ organic installs on Google Play Store.
- **Monetization:** Completely free (₹0 revenue, 0 ads).
- **Primary Audience:** College students preparing for university semester exams.

### The Breakdown
1. **Maintenance Overhead:** Google Play regularly raises the minimum target API level requirement for existing apps.
2. **Time Allocation:** Transitioning into full-time software engineering at Collegedunia left limited bandwidth for unpaid app store compliance updates.
3. **Platform Dependency:** Depending entirely on a closed app store ecosystem without a web fallback meant that account suspension completely severed user access.
